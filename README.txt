PPADA STUDIO — 독립형 웹사이트 소스

실행: index.html을 브라우저로 열면 됩니다.
또는 이 폴더에서 python -m http.server 8080 실행 후 http://localhost:8080 접속.

배포: 이 폴더 안의 파일을 정적 웹 호스팅의 공개 디렉터리에 그대로 업로드하세요.
빌드 명령, npm 설치, ChatGPT 로그인, API 키는 필요하지 않습니다.
도메인은 선택한 호스팅 서비스에 연결하면 됩니다.

파일 구성
index.html: 페이지 구조와 기본 스타일
app.js: 프로젝트 목록, 검색, 분류, 상세창
 gallery.js: 이미지 카드 슬라이드, 마우스·스와이프·키보드 처리
 gallery.css: 슬라이드와 이미지 스타일
 default-cover.svg: 대표 이미지가 없을 때 표시하는 기본 이미지
 images/: 프로젝트 카드 대표 이미지. calendar·gemma는 실제 앱 캡처, laundry·weeding은 실제 사이트 캡처(2026-11-27), 나머지는 기능을 표현한 그림
 records.js: 수상경력·자격증 목록, 메뉴 강조, 스크롤 등장 효과

수정
app.js의 projects 배열에서 이름, 설명, 기능, 기술, 링크를 수정하세요.
수상경력과 자격증은 records.js의 awards, certs 배열에 항목을 추가하세요.
대표 이미지를 지정하려면 해당 프로젝트에 cover: 'images/calendar.jpg' 같은 속성을 추가하고,
그 경로에 이미지 파일을 넣으세요. 없으면 기본 이미지가 표시됩니다.

프로젝트 소개에 들어 있는 기존 서비스 URL 중 일부는 chatgpt.site 주소입니다.
이는 포트폴리오 자체의 호스팅 의존성이 아니라 기존 프로젝트로 이동하는 외부 링크입니다.
각 서비스를 별도로 이전한 후 app.js의 links 값을 새 주소로 바꾸세요.
접근 권한이 필요한 기존 서비스의 공개 범위는 이 소스 배포로 바뀌지 않습니다.

현재 코드의 슬라이드·검색·상세 기능은 브라우저에서 실행되며 별도 서버나 DB를 사용하지 않습니다.
